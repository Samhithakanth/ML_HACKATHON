# Person 1 - Data exploration, labels and candidate generation

Run everything from inside this `person1/` folder. Put the raw data at `data/raw/{train,student_test}/<trip>/` first
(unzip "Student folder.zip"). Full findings, assumptions and the table schemas handed to the other team members are in
[docs/DATA_NOTES.md](docs/DATA_NOTES.md).

```
pip install numpy pandas scipy shapely pyproj pyarrow matplotlib folium networkx
python -m src.data.eda_inventory   # results/eda/trip_inventory.csv
python -m src.data.label_audit     # results/eda/label_audit.csv
python -m src.data.radius_sweep    # results/eda/radius_sweep_by_trip.csv  (train only)
python -m src.data.build_dataset   # data/processed/*.parquet  (not committed, ~38 MB; regenerate)
python -m src.viz.eda_plots        # results/eda/plots/*.png
python -m src.viz.label_check      # results/eda/plots/07_label_alignment_check.png
python -m src.viz.folium_map       # results/maps/*.html
```
`notebooks/01_eda.ipynb` walks through the results (generated by `notebooks/make_eda_nb.py`).
